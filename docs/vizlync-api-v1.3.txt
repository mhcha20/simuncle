            Partner API Documentation
                This API allows authorized partners to fetch product data, place and track orders, and view usage information.
            API Authentication
            All API requests require the following HTTP headers:
                Authorization: Bearer {your_api_key}
                X-Partner-ID: {your_partner_id}
                    API Key

                Base URL
                Note: You can obtain your API key and Partner ID from the Partner Portal.

                    POST
                    /order
                Places a new order for an eSIM product. Returns essential order information only. Use the Order Details endpoint with the returned orderId to retrieve complete order information including eSIM details, pricing, and fulfillment data.
                        Example
                        Try it
                            Copy
                            curl -X POST "https://partner-api.your-domain.com/api/v1/order" \
  -H "Authorization: Bearer your-api-key" \
  -H "X-Partner-ID: your-partner-id" \
  -H "Content-Type: application/json" \
  -d '{
    "productId": "ABCDEF123456",
    "startDate": "2023-11-01"
  }'
                        Response
                            Copy
                            {
  "success": true,
  "orderId": "VLZ123456",
  "message": "Order created successfully"
}
                            Note: The order creation response contains only essential summary information. To retrieve complete order details including eSIM data, pricing, and fulfillment information, use the GET /order/{orderId} endpoint with the returned orderId.

                    POST
                    /order/{orderId}/topup
                Creates a topup order for an existing completed order. This adds additional data/services to an existing eSIM.
                        Example
                        Try it
                            Copy
                            curl -X POST "https://partner-api.your-domain.com/api/v1/order/VLZ123456/topup" \
  -H "Authorization: Bearer your-api-key" \
  -H "X-Partner-ID: your-partner-id" \
  -H "Content-Type: application/json" \
  -d '{
    "productId": "ADDON001"
  }'
                        Response
                            Copy
                            {
  "success": true,
  "data": {
    "topupOrderId": "VLZ789012",
    "originalOrderId": "VLZ123456",
    "status": "completed",
    "message": "Topup order created successfully"
  }
}
                            Note: Topup orders are processed immediately and will show a status of "completed" upon successful creation. The topup data/services are added to the existing eSIM associated with the original order.

                POST
                /order/{orderId}/terminate-plan
            Terminates an active data plan for applicable orders. This deactivates the current plan on the eSIM and activates any queued top-up plan. Only active (non-expired) plans can be terminated.
                For some orders that supports top-up doesn't require the current plan to be terminated before activating the top-up plan, in which case this endpoint does not need to be called and will return an error if called.
                "After the main plan is terminated early, the user should toggle Airplane Mode on and then off to allow the new top-up plan to activate".
                Warning: This action cannot be undone. Any remaining data on the current plan will be lost. A top-up order must already exist for this order.
                    Example
                    Try it
                        Copy
                        curl -X POST "https://partner-api.your-domain.com/api/v1/order/VLZ123456/terminate-plan" \
  -H "Authorization: Bearer your-api-key" \
  -H "X-Partner-ID: your-partner-id" \
  -H "Content-Type: application/json" 
                    Response
                        Copy
                        {
  "success": true,
  "message": "Termination Successful",
}
